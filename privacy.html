Политика конфиденциальности

Действует с 7 ноября 2026 года · Приложение PassKeeper (Android, Windows)

Настоящая политика описывает, как приложение PassKeeper («Приложение») обрабатывает данные пользователей. Суть в одном предложении: все ваши данные остаются у вас — Приложение не имеет серверов, не собирает и не передаёт нам ваши пароли или иное содержимое.

3. Оператор

Оператором Приложения является владелец домена pkeeper.ru (контакты для связи — в разделе «Контакты»). Оператор не получает и не хранит данные пользователей на своих ресурсах.

4. Какие данные обрабатывает Приложение

  • Содержимое сейфов (карточки паролей, логины, заметки, мнемоники) — хранится только на устройстве пользователя в виде зашифрованной базы (AES; ключ шифрования выведен из мастер-пароля пользователя алгоритмом PBKDF2). Мастер-пароль нигде не хранится и не передаётся; восстановить данные без него невозможно, в том числе для оператора.
  • Реестр подключённых сейфов и настройки — локальные настройки приложения на устройстве.
  • Мнемонические фразы — генерируются и обрабатываются локально.

5. Синхронизация через Google Drive

Функция облачных сейфов работает исключительно по явному действию пользователя (подключение облачного сейфа). При этом Приложение:

  • получает ограниченный доступ к Google Drive пользователя в рамках разрешения drive.file: Приложение имеет доступ исключительно к тем файлам и папкам, которые оно само создало для хранения зашифрованных сейфов PassKeeper. Приложение не может просматривать, изменять или удалять любые другие личные файлы пользователя на его Google Диске;
  • передаёт зашифрованные файлы сейфов между устройством пользователя и его собственным Google Drive — не на ресурсы оператора;
  • не использует данные Google для каких-либо иных целей, кроме предоставления функции синхронизации, и соответствует API Services User Data Policy Google (ограниченное использование, без передачи рекламы).
Отключить синхронизацию можно в любой момент: переведите сейф в локальные (меню карточки сейфа) либо удалите облачный сейф — файл на Drive также удаляется по выбору пользователя.

6. Разрешения Android

  • Уведомления — для уведомления быстрого копирования логина/пароля (создаётся только при открытии карточки пользователем);
  • Биометрия — используется системный сканер устройства; биометрические данные обрабатывает Android и не передаёт Приложению;
  • Буфер обмена — скопированные из Приложения данные автоматически стираются по таймеру (настраивается).

7. Чего Приложение не делает

  • не содержит рекламы, аналитики, трекеров и систем телеметрии;
  • не запрашивает доступ к контактам, SMS, геолокации, файлам вне выбранных пользователем файлов сейфов;
  • не продаёт и не передаёт данные третьим лицам.

8. Передача данных третьим лицам

Единственная внешняя система, участвующая в обработке, — Google Drive (по действию пользователя, п. 3). Установка приложения может осуществляться через магазин RuStore — обработка данных на этапе установки подчиняется правилам магазина.

9. Данные детей

Приложение не собирает данные пользователей любого возраста, включая детей. Возрастная категория — 0+.

10. Хранение и удаление

Пользователь управляет всеми данными самостоятельно: удаление сейфа или карточки в Приложении удаляет данные безвозвратно; облачные файлы удаляются с Google Drive пользователя выбором соответствующего пункта меню. Оператор не хранит копий.

11. Изменения политики

Актуальная редакция всегда размещена на этой странице. При существенных изменениях дата в начале страницы обновляется.

12. Соответствие правилам Google API

Приложение использует данные, полученные из Google API (Google Drive), в соответствии с API Services User Data Policy Google, включая требование ограниченного использования (Limited Use): данные пользователя не передаются третьим лицам, не используются для рекламы и не применяются для обучения моделей искусственного интеллекта.

Приложение не использует Google API для создания, распространения или размещения AI NCII (искусственно сгенерированных интимных изображений, созданных без согласия изображённых лиц), не претендует на исключения из этого запрета и не разрешает такое использование третьими сторонами через свои функции.

Общие условия использования Google API регулируются Google APIs Terms of Service.
