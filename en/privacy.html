Privacy Policy

Effective November 12, 2026 · PassKeeper app (Android, Windows, macOS)

This policy describes how the PassKeeper app (the "App") processes user data. In one sentence: all your data stays with you — the App has no servers of its own and never collects or transmits your passwords or any other content to us.

3. Operator

The operator of the App is the owner of the pkeeper.ru domain (see "Contacts" for the support address). The operator does not receive or store user data on its own resources.

4. Data processed by the App

  • Safe contents (password cards, logins, notes, mnemonics) — stored only on the user's device as an encrypted database (AES; the encryption key is derived from the user's master password using PBKDF2). The master password is never stored or transmitted; the data cannot be recovered without it — including by the operator.
  • Registry of connected safes and settings — local app settings kept on the device.
  • Mnemonic phrases — generated and processed locally.

5. Sync via Google Drive and Yandex Disk

The cloud safe feature works only upon an explicit user action (connecting a cloud safe). The user chooses the cloud storage themselves: Google Drive or Yandex Disk. In that case the App:

  • Google Drive: gets limited access under the drive.file permission — only to the files and folders it created itself to store the encrypted PassKeeper safes. The App cannot view, modify, or delete any of the user's other personal files on their Google Drive;
  • Yandex Disk: gets access under the cloud_api:disk.app_folder permission — only to the «PassKeeper» app folder on the user's Disk (visible to the user in their Disk). The rest of the Disk's files are not accessible and are not modified by the App;
  • transfers encrypted safe files between the user's device and the user's own cloud — never to the operator's resources;
  • keeps access tokens only on the user's device (system secure storage);
  • uses Google and Yandex data for no purpose other than providing the sync feature, and complies with Google's API Services User Data Policy (limited use, no advertising transfer) and Yandex's API rules.
Sync can be turned off at any time: switch the safe to local (from the safe card menu) or delete the cloud safe — the cloud file is also deleted at the user's choice.

6. Android permissions

  • Notifications — for the quick-copy notification of a login/password (posted only when the user opens a card);
  • Biometrics — the device's system scanner is used; biometric data is processed by Android and never handed to the App;
  • Clipboard — data copied from the App is automatically wiped on a configurable timer.
  • Internet access — the only internet call the App makes without a user action: requesting the emergency notification file from the pkeeper.ru website (see the summary in section 2); cloud access (section 5) happens only upon a user action.

7. What the App never does

  • no ads, no analytics, no trackers, no telemetry;
  • no access to contacts, SMS, geolocation, or files outside the safe files chosen by the user;
  • no selling or transferring data to third parties.

8. Data transfer to third parties

The external systems involved in processing are the user's own cloud storages: Google Drive and Yandex Disk (by explicit user action, section 5). user action, section 3). Installation of the App may go through the RuStore store — data handling during installation follows the store's own rules.

9. Children's data

The App does not collect data from users of any age, including children. Age rating: Everyone (0+).

10. Storage and deletion

Users control all data themselves: deleting a safe or a card in the App removes the data irreversibly; cloud files are removed from the user's cloud by choosing the corresponding menu option. The operator keeps no copies.

11. Changes to this policy

The current version is always available on this page; significant changes update the date at the top.

12. Compliance with Google API rules

The App uses data obtained from Google APIs (Google Drive) in accordance with Google's API Services User Data Policy, including the Limited Use requirement: user data is not transferred to third parties, not used for advertising, and not used to train artificial intelligence models.

The App does not use Google APIs to create, distribute, or host AI NCII (AI-generated non-consensual intimate imagery), does not claim any exemptions from this prohibition, and does not allow such use by third parties through its features.

General terms of using Google APIs are governed by the Google APIs Terms of Service.
